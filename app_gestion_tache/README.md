 Gestionnaire de tâches en Dart (CLI)

Ce projet est une application en ligne de commande (CLI)développée en Dart.  
Il permet de gérer des tâches avec priorités, dates limites et persistance dans un fichier JSON.  
L’objectif est d’apprendre à structurer un projet Dart, manipuler des fichiers JSON et mettre en place des tests unitaires.


 Fonctionnalités

-Ajouter une tâche avec titre, priorité et date limite optionnelle  
-Lister les tâches triées par priorité  
- Marquer une tâche comme terminée  
- Supprimer une tâche par index  
- Sauvegarde automatique des tâches dans `tasks.json`  
- Chargement des tâches existantes au démarrage  
- Tests unitaires pour vérifier toutes les fonctionnalités  

Exigences

- Dart SDK >= 3.0.0  
- Dépendance : [test](https://pub.dev/packages/test)
